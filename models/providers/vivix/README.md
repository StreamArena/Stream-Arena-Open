# Vivix A1 audio dialogue

`vivix_a1_audio` is the paper's native audio-dialogue configuration: the exact benchmark portrait, `vivix-a1-stream`, `nova-3` ASR, provider-default dialogue and `loongeva_v3.6` voice; 1:1 720p video over Agora. It uses the shared session harness, readiness, input clock and failure accounting. No model-specific void/retry selection is applied.

On supported Linux x86-64 systems, install `pip install -e ".[vivix,judge]"` and set `VIVIX_API_KEY` in the environment or ignored `.env`. The Agora Server SDK is optional and is imported only when joining a live session. Ported adapter tests use mocked services; a successful live provider session is not claimed by those tests.

```bash
streameval batch --system vivix_a1_audio --dry-run
streameval evaluate --system vivix_a1_audio --out runs/vivix
```

Prepare the benchmark media and judge credentials before the evaluation. The adapter uploads the portrait through `/v1/files/images` and caches its unlisted provider URL under `~/.cache/streameval/providers/vivix_images` (override with `STREAMEVAL_VIVIX_IMAGES`). That provider URL is publicly fetchable; do not use private portraits. Credentials and session join tokens stay out of exported results.

The configured workspace session cap is 300 seconds including setup/readiness. A provider early end remains a failure. Cost estimates use session minutes because no public currency price was available. API access, billing and SDK platform support must be verified in the deployment environment. Historical paper observations are not regenerated by the offline adapter tests.
